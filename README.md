=======================使用方法=====================

tip:本工具不涉及逆向，破解，绕过权限，调用应用API等等侵犯行为

重要：电脑环境python >3.7,<3.10

程序直接运行：运行main.py

gui：运行jsoneditor.py

yolo:运行yolom.py

打包成exe:运行package.py，打包工具目录.\dist\HBM


=======================版本信息=====================

当前版本不支持GPU优化
adb:支持点击、滑动、多线程复杂点击

opencv：存在旋转匹配、颜色匹配，可嵌套查找，不支持二值化

yolo：支持寻找敌人，攻击，替身；不支持cd计算，陷阱，攻击预告，判断道具，判断被击状态；只能选择[百战]佩恩[天道]为己角色，目前该模型在副本罡体秘境和烈焰秘境通关率相对较高

gui:决斗场：暂不支持自定义点击
    商店：开放部分功能仅供测试

高度适配：雷电模拟器安卓7.1
